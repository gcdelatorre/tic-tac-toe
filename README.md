# Tic Tac Toe

A **Tic Tac Toe** game built with React. I made this as a refresher project after taking a short break from React.  
It helped me practice **state management**, **useEffect**, and **component-based game logic**.  
This project also served as a way to **practice design patterns and problem-solving approaches** that will be useful for **future real-world projects**.

---

## 🕹️ Features

- Two-player local gameplay (**Player X** vs **Player O**)  
- Detects **wins**, **draws**, and **invalid moves**  
- Displays **current player turn**  
- **Restart button** to reset the game  
- Highlights when the game is over

---

## 🛠️ Skills & Concepts Practiced

- React **state and effect management**  
- **Component-based architecture**  
- Implementing **game logic patterns** (turn-taking, win detection, state updates)  
- Planning steps to **solve problems algorithmically**  
- Preparing for **real-world projects** by applying patterns even in small projects
