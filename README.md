# Tic Tac Toe (React)

A **Tic Tac Toe** game built with React. I made this as a refresher project after taking a short break from React.  
It helped me practice **state management**, **useEffect**, and **component-based game logic**.

---

## 🕹️ Features

- Two-player local gameplay (**Player X** vs **Player O**)  
- Detects **wins**, **draws**, and **invalid moves**  
- Displays **current player turn**  
- **Restart button** to reset the game  
- Highlights when the game is over
